## Project .env setup

1. Copy `.env.example` to `.env` (`cp .env.example .env`)
2. Fill in all required keys in the new file with the correct values for your environment (e.g. API keys, Supabase credentials, etc.).

## Starting the project:

Run the dev server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

## Building the project

To create a production build:

```bash
bun run build
```
